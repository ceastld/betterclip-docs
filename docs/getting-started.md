# 快速开始

BetterClip 以后台进程方式运行。日常入口主要是**系统托盘**和**主窗口首页**。

## 托盘

托盘图标提示文字为 **BetterClip**。左键单击图标会打开**剪贴板**窗口。

右键菜单常见项：

| 菜单项 | 作用 |
|--------|------|
| **打开主窗口** | 打开主窗口首页 |
| **剪贴板** | 打开剪贴板历史 |
| **收藏** | 打开收藏 |
| **设置** | 打开设置 |
| **帮助** | 打开应用内帮助 |
| **退出** | 退出程序 |

可在主窗口首页关闭 **显示托盘图标**；关闭后进程仍可在后台运行，热键与主页入口一般仍可用。

## 主窗口首页

从托盘选择 **打开主窗口**，进入首页。常见快捷入口包括：

- **剪贴板**、**超级面板**、**超级菜单**、**书签**（以界面按钮为准）
- 侧栏还可进入 **局域网互传**、各类设置、**帮助**、**数据管理**

首页还可查看与 Quicker 的连接状态（**Quicker → 宿主** / **宿主 → Quicker**）。未安装 Quicker 时，核心剪贴板功能仍可用，仅相关增强不可用。

关闭主窗口时，界面可能提供缩小到托盘、后台运行或退出等选项，请以当前版本对话框为准。

## 打开剪贴板与收藏

| 方式 | 说明 |
|------|------|
| 托盘左键 | 打开剪贴板 |
| 托盘右键 → **剪贴板** / **收藏** | 直接打开对应窗口 |
| 主窗口首页 | 点击 **剪贴板** 等入口 |
| 全局热键 | 在 **设置 → 个性化 / 触发** 中配置「显示/隐藏剪贴板窗口」「收藏面板」等（具体组合以你保存的设置为准） |

剪贴板窗口标题栏通常可在 **剪贴板** 与 **收藏** 标签间切换；窄屏下部分入口可能改走主窗口。
