# 快捷键

下文 "`` ` ``" 指主键盘 Esc 下方的反引号键（Windows 键名 `Oem3`）。

## 全局快捷键（默认值）

在任意应用中可用，需要 ClipHost 在运行。

| 默认快捷键 | 作用 | 修改位置 |
| --- | --- | --- |
| `Ctrl` + `` ` `` | 显示 / 隐藏剪贴板窗口 | 设置 → 触发 → 显示/隐藏剪贴板窗口 |
| `Ctrl` + `Shift` + `` ` `` | 显示 / 隐藏收藏面板 | 设置 → 触发 → 收藏面板 |
| `Alt` + `` ` `` | 便捷粘贴：**按住**弹出最近剪贴板预览，滚轮或方向键切换，**松开**即粘贴选中项 | 设置 → 便捷粘贴 → 便捷粘贴 |
| `Win` + `` ` `` | 打开超级菜单（窗口、文件、收藏、书签、文本、剪贴板），不需要先打开剪贴板窗口，也不依赖 Quicker | 设置 → 触发 → 打开超级菜单 |

- 每项留空表示禁用。
- 组合键冲突时设置页会给出提示；例如便捷粘贴与"显示/隐藏剪贴板窗口"设成同一组合时，便捷粘贴不会生效。

## 可选触发方式（默认关闭或需要开启）

| 触发 | 作用 | 开启位置 |
| --- | --- | --- |
| `Win` + `V` | 打开剪贴板窗口。会通过注册表禁用系统的 Win+V 剪贴板历史，修改后需**重启 Windows 资源管理器**才生效 | 设置 → 触发 → 使用 Win+V 打开剪贴板 |
| 输入 `vv` 后按 `Tab`，或连按三次 `v` | 自动删掉刚输入的字母并显示剪贴板窗口 | 设置 → 触发 → 文本指令 vv+Tab / vvv |
| 按住鼠标侧键 X1 / X2 并滚动滚轮 | 打开便捷粘贴并切换条目；松开侧键粘贴，右键取消。只单击侧键（不滚动）时保留侧键原有行为 | 设置 → 便捷粘贴 → 鼠标侧键 + 滚轮 |

## 剪贴板窗口内

剪贴板列表中的按键：

| 按键 | 作用 |
| --- | --- |
| `Ctrl` + `F` | 聚焦搜索框（可用输入法） |
| `↑` / `↓` | 上一条 / 下一条 |
| `Home` / `End` | 第一条 / 最后一条 |
| `Shift` + `↑` / `↓` / `Home` / `End` | 连续多选（搜索框聚焦时不生效） |
| `Ctrl` + `C` | 复制选中项 |
| `Delete` | 删除选中项 |
| `Ctrl` + `P` | 置顶 / 取消置顶 |
| 搜索框内 `Enter` | 粘贴当前选中项 |
| 搜索框内 `Esc` | 关闭窗口 |

数字键粘贴：开启 **设置 → 剪贴板 → 使用数字键进行粘贴** 后，`1`–`9`、`0` 粘贴当前列表对应位置的条目。

无焦点模式（**设置 → 剪贴板 → 无焦点模式**）开启时，剪贴板窗口不抢前台焦点也能接收按键；关闭后打开窗口会激活并聚焦搜索框。

## 便捷粘贴相关选项

位于 **设置 → 便捷粘贴**：

| 选项 | 说明 |
| --- | --- |
| 非置顶条数 | 浮窗里最多显示的最近（非置顶）条目数；置顶条目全部排在末尾，不计入上限 |
| 记忆选中项 / 记忆有效期（秒） | 有效期内再次打开时，自动切到上次条目的下一项 |
| 爆发间隔（秒）、队列上限、空闲超时（秒） | 连续粘贴的队列规则：相邻条目创建时间超过爆发间隔即停止收入；一次最多包含"队列上限"条；超过空闲超时没有下一次粘贴则自动取消 |
