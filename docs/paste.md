# 粘贴与便捷粘贴

从历史或收藏把内容送回当前目标窗口。除主窗口列表粘贴外，还提供**便捷粘贴**浮层与**连续粘贴（先进先出）**。

## 在列表中粘贴

- 按 **列表项粘贴触发方式** 单击或双击条目（在列表常用设置或 **设置 → 剪贴板** 中配置）
- 方向键选择条目后，可按 **Enter** 粘贴（以当前焦点为准）
- 右键可选 **粘贴**、**规范粘贴**、**纯文本粘贴**
- 多选后可 **按选择顺序粘贴** / **逆序粘贴**
- 可开启 **使用数字键进行粘贴**：在合适焦点条件下用数字键对应列表序号

更多粘贴相关选项（粘贴前延迟、默认纯文本/规范粘贴、Shift+Insert 进程列表等）见 [设置总览](./settings.md)。

## 便捷粘贴

便捷粘贴是叠在主窗口之上的快速回贴，**不替代**完整剪贴板窗口。全局热键在 **设置 → 个性化** 中配置「便捷粘贴」（产品说明中常见示例为 **Alt+`**，以你实际保存的为准）。

按住便捷粘贴快捷键进入会话时（设置页 **快捷操作** 说明）：

- **Alt** 为引导键；松开 **Alt** 粘贴选中项，或执行已武装的操作
- 用**鼠标滚轮**或 **↑** / **↓** 或连按 **`** 切换条目（循环）
- **1**：主操作（文本类通常为模拟输入）
- **2**：次操作（如打开链接或本地路径）
- **D**：删除当前条目
- **E**：粘贴并发送回车
- **Q**：以当前项为终点武装**连续粘贴（先进先出）**；之后每次便捷粘贴只贴队列头一条
- 图片条目可点「贴图」（需已安装 Snipaste 或 PixPin）
- **Esc**：取消当前会话

在 **设置 → 便捷粘贴** 还可配置非置顶条数、选择记忆、爆发间隔、队列上限、空闲超时等。

## 连续粘贴（先进先出）

适合按固定顺序连续贴多条内容。

1. 在剪贴板列表多选或选定范围后，右键选择 **连续粘贴…**
2. 打开标题为 **连续粘贴（先进先出）** 的面板；提示类似「最早在上…」，并可能显示 **终点** 徽章
3. 确认后点 **开始**（或 **取消**）

也可在便捷粘贴会话中按 **Q** 武装连续粘贴队列。队列相关参数在 **设置 → 便捷粘贴 → 连续粘贴** 分组中调整。
