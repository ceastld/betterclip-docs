# 使用说明

本页按当前 GPUI 原生界面（0.31.12 起）编写。具体选项名称以软件内 **设置** 为准；快捷键汇总见 [快捷键](./hotkeys.md)。

## 打开剪贴板

- 全局快捷键：默认 `Ctrl` + `` ` `` 显示 / 隐藏剪贴板窗口，`Ctrl` + `Shift` + `` ` `` 打开收藏。
- 可选：`Win` + `V`、文本指令 `vv` + `Tab` / `vvv`（需在 **设置 → 触发** 开启）。
- 通过 Quicker 动作「剪贴板 n10」启动。
- 程序常驻系统托盘（提示文字为 "ClipHost GPUI · 剪贴板"），托盘菜单可退出程序。

窗口出现的位置在 **设置 → 触发 → 打开剪贴板窗口时的位置** 设置。

## 主窗口

- 标题栏是搜索框；剪贴板与收藏用图标切换，**暂停**（暂停记录）和 **设置** 在底栏。
- 列表上方是分类标签（如文字、图片、网址、富文本等），可在 **设置 → 剪贴板 → 分类标签** 自定义；**黑名单** 用于排除不想记录的来源。
- 右下角的紧凑弹层可以快速调整列表外观和交互预设。
- 历史列表有"返回顶部"按钮；也可开启 **闲置后自动回到顶部**（默认关闭）。
- 悬停的文字提示中，网址可以直接点击打开。

## 粘贴

- **列表项粘贴触发方式**（设置 → 剪贴板）：单击粘贴、单击复制后双击粘贴，或仅双击粘贴。
- **使用数字键进行粘贴**：开启后按数字键粘贴列表对应位置的条目。
- **富文本默认处理方式**：复制、粘贴、拖放时可只保留文字（去掉格式及内嵌图片；独立图片、文件、动作步骤不受影响）。
- 其它粘贴选项：默认规范粘贴、粘贴前延迟、粘贴文本时自动换行、对指定进程改用 `Shift` + `Insert` 粘贴。

### 便捷粘贴

按住 `Alt` + `` ` ``（默认）弹出最近剪贴板预览，滚轮或方向键切换条目，松开即粘贴。也可在 **设置 → 便捷粘贴** 改为"按住鼠标侧键 X1 / X2 + 滚轮"触发，右键取消。

## 编辑条目

编辑窗口吸附在剪贴板右侧并保持等高，随主窗口移动、缩放和显隐；在列表中选择其它条目时同步切换。编辑器分"内容 / 属性"两页：内容页按类型提供编辑能力，属性页显示来源、路径及技术信息。

## 收藏

- 历史条目右键菜单可直接收藏：保存到总目录，或悬停选择指定目录、按路径搜索目录；保存后气泡显示位置，可撤销。
- 收藏、面板、自定义目录和分类支持拖拽整理（移动、复制、排序、撤销）；拖放提示会区分"插入到同级"和"放进文件夹"。
- 删除收藏夹时会清理相关引用；已失效的行可以在悬停时移除。

## 窗口失焦行为

**设置 → 剪贴板 → 窗口失焦行为**：失去焦点时**普通隐藏**、**贴边隐藏**或**自动折叠为标题栏**。

## 超级菜单与文件菜单

- 默认 `Win` + `` ` `` 打开超级菜单，包含 **窗口、文件、收藏、书签、文本、剪贴板** 六个分类，切换栏位于当前屏幕顶部居中。
- 超级菜单、文件菜单和文本操作的设置合并在 **设置 → 超级菜单** 一个分类里，分区标签与长页滚动联动。
- 文件菜单维护自己的 **自定义目录** 列表，可设置排序方式与显示方式。
- **设置 → 资源管理器** 可开启"记录资源管理器历史"，并设置历史记录上限、重开菜单显示数量。

## 打开 / 另存为窗口的目录跳转

在标准"打开 / 另存为"对话框（含 Chrome 等浏览器的另存为窗口）中跳转到目标文件夹时，会保留已填写的文件名；繁忙或失败时停止重复跳转。部分原生增强目前只有 x64 实现。

## 局域网互传

- 互传面板贴附在剪贴板右侧，与编辑共用右栏；底栏入口显示打开状态。
- 打开互传时，可点击历史条目或拖入内容发送；输入草稿会保留。
- 历史条目右键菜单也可直接发送到局域网设备。
- **收到文件后加入剪贴板列表**（默认关闭）：完整接收的多个文件合成一条本机文件记录；加入失败可单独重试，无需重传。

## Windows 设备间剪贴板同步（0.31.21 起，默认关闭）

在局域网 **设备与连接** 中，可为已配对的电脑开启文本、静态图片自动同步：

- 总开关以及每台设备的发送、接收初始都是关闭的；开启后文本默认允许，图片需要另外开启。
- 每台设备可分别选择：收到的内容是否保存到历史、是否替换当前剪贴板（可以只收集历史，也可以临时跨设备接力）。
- 连续相同内容不会重复发送；收到与当前相同的内容不重复写入；延迟或重试送达的内容不会覆盖当前剪贴板。
- 文件仍使用手动互传。配对或打开互传窗口**不会**自动授权同步。

已知边界：真实两台 Windows 收发、与微信或系统同步并存、锁屏 / 睡眠 / 断线场景尚待现场验证。

## 外观与语言

**设置 → 全局**：界面主题、背景色 / 前景色、窗口背景图、背景混合比例、背景毛玻璃、界面语言。

## 与 Quicker 配合

**设置 → 剪贴板** 中与 Quicker 相关的选项：**收集Quicker步骤**、**剪贴板改变时触发自定义动作**、**预处理表达式**。超级菜单等功能不依赖 Quicker。
