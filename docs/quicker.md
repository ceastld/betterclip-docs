# 与 Quicker

BetterClip **不依赖** Quicker 即可运行。安装 Quicker 后，可用动作、热键和部分增强能力管理同一套剪贴板宿主。

## 基本关系

| | 说明 |
|--|------|
| 独立运行 | 剪贴板历史、粘贴、设置、收藏等核心能力在 BetterClip 内完成 |
| 可选增强 | Quicker 可启动/管理进程、转发命令、提供拖放与动作相关能力 |
| 未安装 Quicker | 仅增强项不可用，**不挡**启动与日常使用 |

主窗口首页可显示连接状态：**Quicker → 宿主**、**宿主 → Quicker**。

## 常见增强点

- 通过分享动作（例如「剪贴板 n10」）唤起或管理 BetterClip
- **设置 → 剪贴板** 中的 **收集Quicker步骤**：复制时收集步骤
- **剪贴板改变时触发自定义动作**：填写 Quicker 动作 ID（需插件/RPC 可用）
- **预处理表达式**：支持与 Quicker 相同风格的 `$=` / `$$` 表达式（以设置说明为准）
- 超级面板 / 收藏中的 **添加动作**：通常需从 Quicker 拖拽或在面板中管理

## 与旧版剪贴板插件

BetterClip（0.30.x 一代，包名 `cea.clip.quicker`）与旧版 Quicker 进程内剪贴板（0.8.x）是**并存**的两代产品，不是同一界面的两套皮肤。两代启动时默认互不结束对方进程。新能力默认落在 BetterClip 这一代。
