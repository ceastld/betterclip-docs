# 功能介绍

下面按使用场景概括当前能力。具体默认选项、完整快捷键表等仍可能随版本调整，请以软件内设置为准。

## 剪贴板历史

- 自动记录复制内容，便于稍后回贴
- 支持搜索、筛选、置顶、删除
- 可查看条目的来源进程
- 粘贴时可选择纯文本或标准文本等方式（以界面选项为准）

## 收藏夹

- 将常用内容收入收藏，按树形结构管理条目
- 可从剪贴板内容直接收藏
- 提供与云同步相关的能力（规则与默认开关以软件内说明为准）

## 粘贴

- 从历史或收藏中选中条目后粘贴到当前目标窗口
- **连续粘贴（FIFO）**：按先进先出队列批量粘贴；可按范围选择多条再贴
- **便捷粘贴**：在主窗口之上叠加的快速回贴（默认快捷键为 **Alt+`**），用于加快回贴，不替代完整主窗口

## 主窗口收起方式

窗口如何「消失」由你在设置中选择，几种方式**互不混用**：

| 方式 | 行为概要 |
|------|----------|
| **Hide** | 整窗隐藏 |
| **Fold** | 收到标题栏；收起后仍可用数字键等快捷方式粘贴（键盘假焦点场景） |
| **EdgeHide** | 贴边隐藏；在窗外点击时会先尝试贴边，若当前位置不适合贴边则回退为普通 Hide |

另支持无焦点相关选项，便于在不抢占前台应用的情况下操作剪贴板（细节见设置页）。

## 设置与捷径

- 程序内提供设置界面，可调整窗口行为、粘贴相关选项等
- **捷径面板**等与 Quicker 相关的能力为可选增强；未安装 Quicker 时不影响其它功能

## 说明

- BetterClip（当前 0.30.x 一代）与旧版 Quicker 进程内剪贴板插件（0.8.x）是**并存的两代产品**，不是同一界面的两套皮肤
- 新功能默认落在 BetterClip 这一代；不必假设与 0.8 功能一一对应
