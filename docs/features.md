## 能力速览

- **剪贴板历史**：搜索、筛选、置顶、删除、来源进程、多种粘贴方式
- **收藏**：分类排序、从历史收藏、可在超级面板中整理
- **便捷粘贴**与**连续粘贴（先进先出）**：快速回贴与按序批量粘贴
- **窗口失焦行为**：**普通隐藏**、**贴边隐藏**、**自动折叠**（互不混用）
- **超级面板 / 超级菜单**：捷径与集中入口
- **局域网互传**：局域网内传文本与文件
- **设置与数据管理**：外观、触发、剪贴板参数、数据目录
