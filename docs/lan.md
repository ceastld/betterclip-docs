# 局域网互传

在同一局域网内的多台电脑之间传递文本、图片或文件。入口在主窗口侧栏 **局域网互传**。

## 开启

1. 打开主窗口 → **局域网互传**
2. 使用开关 **开启局域网互传** / **关闭局域网互传**
3. 状态文案可能为 **已连接**、**连接异常** 或 **未开启**

在 **设备与连接** 中可查看或修改：

- **设备名称**、**端口**（改后点 **保存**）
- **配对码**（可 **刷新**）；提示：在另一台设备输入此代码完成配对
- 证书指纹等安全信息（悬停或详情中可见）

## 发现与配对

1. 在 **附近设备** 中点 **重新扫描**（扫描中显示「扫描中…」）
2. 对可配对设备输入 **6 位配对码** 后点 **配对**
3. 已配对设备可 **解除**

设备状态文案可能包括：**已配对**、**可配对**、**离线**。

## 发送与接收

- 在会话列表选择 **所有设备** 或某一已配对设备
- **开始传递**：发送一条消息，或添加图片/文件
- 输入框在已开启时可输入消息；支持添加图片（预览）或任意文件
- 发送状态可能包括：等待发送、发送中、已送达、部分送达、发送失败、已接收、已暂存、已取消等
- 失败时可 **重试** 或 **取消**；附件可 **打开** / **定位**

未开启局域网互传时，输入框会提示先开启后再发送。

## 说明

- 双方都需要安装并开启局域网互传，且网络互通
- 离线设备可能显示「上线后自动发送」类提示
- 具体端口与防火墙策略请按本机环境放行（以实际设置为准）
