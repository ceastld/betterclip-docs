# 面板与菜单

除剪贴板与收藏窗口外，BetterClip 还提供**超级面板**与**超级菜单**，用于捷径、收藏夹整理和集中入口。

## 超级面板

从主窗口首页的 **超级面板** 入口打开（也可通过设置中的面板相关热键/入口，以界面为准）。

常见能力：

- 以网格、列表、紧凑或仅图标等**面板样式**展示条目
- 管理收藏夹、文本、文件、文件夹、动作等
- 右键可添加文本、收藏夹、动作、当前网址、文件夹、文件、批量文本，或刷新

在 **设置 → 面板** 可配置：

| 选项 | 说明 |
|------|------|
| **打开超级面板时的位置** | 弹出位置 |
| **文件夹单击默认行为** | 打开 / 复制 / 粘贴 |
| **文件单击默认行为** | 打开 / 复制 / 粘贴 |
| **面板样式** | 网格 / 列表 / 紧凑 / 仅图标 |

添加 **动作** 时，界面可能提示从 Quicker 拖拽或在面板中管理；未安装 Quicker 时相关项不可用，不影响其它面板内容。

## 超级菜单

超级菜单是全屏（或大范围）快捷界面，把窗口、文件、收藏、剪贴板等入口集中到一处。可从首页 **超级菜单** 打开。

常见能力（以当前版本为准）：

- 窗口切换：缩略图、置顶、最小化/最大化、关闭、透明度等
- 剪贴板列表与预览：粘贴、复制、固定、打开、删除
- 浏览器书签（需相应权限/连接）
- 文件与资源管理器相关菜单项

在侧栏 **菜单** 设置中可调整字体大小、菜单最大宽度、显示位置、是否显示设置按钮、添加收藏、窗口菜单、浏览器书签、按进程分组等。文件菜单还可配置自定义目录、排序与显示方式等。
