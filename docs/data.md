# 数据与路径

程序文件与用户数据分开存放，便于升级程序而不混淆个人历史与配置。

## 默认路径

| 用途 | 路径 |
|------|------|
| 程序安装目录 | `%LocalAppData%\Programs\BetterClip` |
| 用户数据 | `%LocalAppData%\BetterClip\` |

用户数据目录下通常包含配置、历史库、日志与 WebView 数据等（具体子目录以本机为准）。

## 数据管理页

主窗口侧栏打开 **数据管理**，常见操作：

- 查看或更改**数据位置**（内置默认 / 自定义等；若存在环境变量覆盖，界面会提示）
- **浏览**、**保存**、**恢复默认**
- **打开**数据目录、日志目录或配置目录
- **清空非置顶** / **清空全部** 历史（通常需确认）
- **复制最新日志**，便于反馈问题时附上 ClipHost 日志

更改数据位置前请先退出不必要的剪贴板窗口，并确保有权限访问目标文件夹。迁移后若列表为空，请确认指向的是包含原数据的目录。

## 相关说明

- 历史上限与自动清理在 **设置 → 剪贴板** 的 **记录历史条目上限** 中配置
- 清空操作与撤销策略以当前版本确认框文案为准
