# 剪贴板历史

复制内容后，BetterClip 会记入历史，便于稍后搜索、粘贴、置顶或收藏。

<ClipboardWindowPreview caption="示意：分类、置顶（金色边）与当前选中项。点分类可切换示意数据。" />

## 分类与搜索

列表上方常见分类（以界面为准）：**默认**、**星标**、**文本**、**图片**、**文件** 等。若开启「单独显示置顶项」，还可能出现 **置顶** 分栏；也可按**来源进程**筛选。

支持搜索历史内容。标题栏可暂停/恢复剪贴板采集（避免某段时间的复制写入历史）。

## 筛选

打开 **筛选** 后，可按使用状态、创建时间等缩小范围，例如：

- **粘贴后置顶**
- 使用状态：全部 / 已使用 / 未使用
- 创建时间：忽略、近几天、按范围或按日期等

用 **重置** / **完成** 结束筛选。列表还可 **加载更多**、**回到开头**。

## 列表常用设置

底栏 **设置** 可打开列表常用选项（完整项见 [设置总览](./settings.md)），例如：

- 列表显示密度、标准/简洁模式
- **单独显示置顶项**
- 列表图片悬停预览与最大高度
- **无焦点模式**、**窗口失焦行为**
- **列表项粘贴触发方式**（单击粘贴，或单击复制、双击粘贴等）

## 右键菜单（常见项）

在条目上右键，常见操作包括：

| 操作 | 说明 |
|------|------|
| **粘贴** / **规范粘贴** / **纯文本粘贴** | 不同粘贴方式 |
| **按选择顺序粘贴** / **逆序粘贴** | 多选时按顺序贴 |
| **连续粘贴…** | 打开先进先出队列（见 [粘贴与便捷粘贴](./paste.md)） |
| **复制** | 写回系统剪贴板 |
| **编辑** | 内联或快速编辑 |
| **收藏** | 收入收藏夹 |
| **置顶** / **取消置顶** | 固定常用项 |
| **删除** | 删除条目 |
| **去除重复** / **按行拆分** / **按文件拆分** | 整理历史 |
| **发送到局域网** | 发往已配对设备（见 [局域网互传](./lan.md)） |
| **Snipaste贴图** / **PixPin贴图** | 需本机已安装对应软件 |
| **定位文件** / **定位文件夹** | 针对文件类条目 |

多选时可能出现浮层：**顺序粘贴**、**逆序粘贴**、**取消选择**。

## 底栏

- 显示总数 / 已加载数量
- **添加**：手工添加内容（以菜单为准）
- **清空**：**清空全部** 或 **清空非置顶**（通常会确认；部分版本支持短时撤销）

## 相关设置

在 **设置 → 剪贴板** 可配置黑名单、历史上限、粘贴延迟、默认纯文本/规范粘贴、数字键粘贴等。详见 [设置总览](./settings.md)。
