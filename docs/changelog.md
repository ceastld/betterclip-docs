# 更新记录

按版本列出用户可见变更。发版后会在此追加；更细的工程说明以产品仓库的 release notes 为准。

## v0.30.31（2026-08-13）

- 优化折叠收起：悬停可展开/收起，置顶时仍可通过标题栏关闭窗口
- 修复贴边隐藏拖动相关问题，并改进自动收起策略
- 设置弹层改为居中显示，并优化自动隐藏与按钮样式
- 增加先进先出粘贴队列，支持按范围批量粘贴
- 优化程序启动与版本同步，减少安装/更新后版本不一致
- 优化与 Quicker 插件的通信，降低连接失败与程序集冲突
