# 更新记录

按版本列出用户可见变更（由产品仓 release notes 改写）。更早大版本可后续追加。发版后请以软件内实际行为为准。

## v0.30.32（2026-08-13）

- 修复无焦点模式下离开窗口后仍吞键盘输入的问题
- 修复贴边隐藏下点击窗外不收起：先贴边，不适合时回退为普通隐藏
- 置顶时不再因外部点击误收起

## v0.30.31（2026-08-13）

- 优化自动折叠：悬停可展开/收起，置顶时仍可通过标题栏关闭
- 修复贴边隐藏拖动问题，并改进自动收起
- 设置弹层居中，并优化自动隐藏与按钮样式
- 增加先进先出粘贴队列，支持按范围批量粘贴
- 优化启动与版本同步，减少安装/更新后版本不一致
- 优化与 Quicker 插件通信，降低连接失败

## v0.30.30（2026-08-10）

- 修复便捷粘贴开启时全局拦截滚轮，影响其它窗口滚动的问题
- 修复便捷粘贴卡住时数字键被吞、无法输入 `@` 的问题
- 便捷粘贴异常未结束时约 2 分钟后自动取消
- 修复捷径面板中动作项标题、图标偶发空白

## v0.30.29（2026-08-06）

- 安装目录固定为每用户路径，升级更易覆盖
- 修复托盘场景下系统确认框卡住、按钮无响应
- 修复复制提示进出场时高度抖动
- 管理员权限或旧实例无法结束时给出明确提示
- 历史自动清理改为静默裁剪；批量删除确认改在设置中完成

## v0.30.28（2026-08-03）

- 增强与 Quicker 的调用稳定性
- 优化便捷粘贴会话条目顺序
- 修复设置页偶发加载异常
- 局域网互传：设备发现配对、文件分享；修复在线探测与消息时间，支持图片预览

## v0.30.27（2026-08-01）

- 修复关闭「以管理员身份运行」后仍保持提权，导致拖拽与部分粘贴失效

- 修复全局键盘钩子误拦截程序自身注入的粘贴快捷键
- 优化导出日志时的读取兼容
