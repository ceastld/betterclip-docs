# 收藏

把常用文本、图片、文件、链接等收进收藏，方便反复粘贴或在超级面板中整理。

## 打开方式

- 托盘右键 → **收藏**
- 剪贴板窗口标题栏切换到 **收藏**
- 主窗口相关入口（以界面为准）
- 可在设置中配置「收藏面板」热键

## 浏览与筛选

- 搜索框提示类似 **搜索收藏内容...**
- 分类常见：**全部**、**文本**、**图片**、**文件**、**链接**、**收藏夹**、**其他**
- **排序**：按最近更新 / 按标题排序

## 从剪贴板收藏

在剪贴板历史条目上右键选择 **收藏**。成功后通常有「已收藏」提示，并可能弹出收录对话框，用于选择目标收藏夹、标题与内容摘要后确认。

## 添加菜单

收藏页底栏 **添加**（或同类入口）常见项：

- 添加文本
- 管理收藏夹…
- 添加动作
- 添加当前打开网址
- 添加文件夹 / 添加文件
- 批量添加文本

**管理收藏夹**、**添加动作** 等完整整理能力，界面可能提示前往**超级面板**或通过 Quicker 管理，而不是在本页完成全部编辑。

## 右键常见项

| 操作 | 说明 |
|------|------|
| **粘贴** / **复制** | 回贴或写回剪贴板 |
| **编辑** | 修改条目 |
| **移除** | 从收藏删除 |
| **定位文件** / **定位文件夹** | 文件类条目 |
| **在超级面板中打开** | 针对收藏夹等，跳到面板整理 |

## 与超级面板

超级面板适合管理收藏夹树、拖放动作与文件夹结构。详见 [面板与菜单](./panel-and-menu.md)。

## 设置中的收藏相关项

设置里可见的收藏相关选项主要包括 **默认插入位置**（开头/末尾）、**默认打开的收藏夹** 等；其余以软件当前设置为准。
