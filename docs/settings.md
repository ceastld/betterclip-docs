# 设置总览

主窗口侧栏提供设置与管理入口。下列标签与软件界面一致；**具体默认值以你保存的配置为准**，本文不做默认值约定。完整快捷键组合请在设置中查看与修改，不在此列出对外固定键位表。

## 侧栏地图

| 入口 | 说明 |
|------|------|
| **首页** | 快捷打开与系统操作 |
| **局域网互传** | 见 [局域网互传](./lan.md) |
| **个性化** | 外观、部分系统与热键 |
| **触发** | 打开位置、Win+V、文本指令等 |
| **便捷粘贴** | 便捷粘贴与连续粘贴参数、快捷操作说明 |
| **剪贴板** | 历史、粘贴、失焦、无焦点等 |
| **面板** | 超级面板 |
| **文本操作** | 文本处理规则管理 |
| **菜单** | 超级菜单与文件菜单等 |
| **帮助** | 应用内帮助 |
| **数据管理** | 见 [数据与路径](./data.md) |

标题栏支持搜索设置项（**搜索设置项…**），便于快速定位。

## 个性化

常见分组包括外观、系统与快捷键相关项：

| 选项 | 说明摘要 |
|------|----------|
| **界面主题** | 跟随系统 / 浅色 / 深色 / 自定义 |
| **背景色** / **前景色** | 自定义主题时使用 |
| **窗口背景图**、**背景混合比例**、**背景毛玻璃** | 窗口外观 |
| **开机自启** | 随系统启动 |
| **以管理员身份运行** | 提权运行（影响拖拽等场景时请按提示操作） |
| **显示/隐藏剪贴板窗口** | 全局热键（可配置） |
| **收藏面板** | 全局热键（可配置） |
| **便捷粘贴** | 全局热键（可配置） |

## 触发

| 选项 | 说明摘要 |
|------|----------|
| **打开剪贴板窗口时的位置** | 如鼠标右下、屏幕中心、鼠标周围等 |
| **使用 Win+V 打开剪贴板** | 接管系统 Win+V；可能需重启资源管理器 |
| 文本指令（如 vv+Tab / vvv） | 以设置页说明为准 |

## 便捷粘贴

| 分组 | 常见选项 |
|------|----------|
| 常规 | **非置顶条数** |
| 选择记忆 | **记忆选中项**、**记忆有效期（秒）** |
| 连续粘贴 | **爆发间隔（秒）**、**队列上限**、**空闲超时（秒）** |
| **快捷操作** | 只读说明（滚轮/数字键/Q/E 等），见 [粘贴与便捷粘贴](./paste.md) |

## 剪贴板

| 分组 | 常见选项 |
|------|----------|
| 控制 | **黑名单**、**记录历史条目上限**、**隐藏窗口后清空筛选**、**窗口失焦行为**、**无焦点模式** |
| 复制 | **收集Quicker步骤**、**允许重复复制**、**剪贴板改变时提示**、**提示位置**、**剪贴板改变时触发自定义动作**、**忽略空白剪贴板内容**、**预处理表达式** |
| 粘贴 | **粘贴前延迟**、**使用 Shift+Insert 粘贴的进程**、**粘贴文本时自动换行**、**默认纯文本粘贴**、**默认规范粘贴**、**使用数字键进行粘贴**、**列表项粘贴触发方式**、**单独分栏显示置顶项**、列表图片预览相关、**列表布局密度**、**列表显示模式** |

另有清空确认、按行拆分最大行数等选项。窗口失焦三项含义见 [窗口行为](./window.md)。

## 面板与菜单

见 [面板与菜单](./panel-and-menu.md)。菜单侧还可配置超级菜单字体、宽度、书签、窗口菜单，以及文件菜单的目录与显示方式等。

## 列表内快捷设置

剪贴板窗口底栏 **设置** 提供列表常用子集（密度、置顶分栏、失焦行为、粘贴触发方式等），与完整设置页对应项一致。
