# 窗口行为

剪贴板窗口如何在失焦后「消失」，以及是否抢占前台焦点，可在设置中调整。几种消失方式**互不混用**；选哪一种以你在界面中的选择为准（本文不规定产品默认值）。

全局热键 **显示/隐藏剪贴板窗口**（在 **设置 → 个性化** 中配置）用于打开或收起窗口：未显示则打开；已打开但不在前台则激活；已在前台则收起。具体组合以你保存的为准。

## 窗口失焦行为

在列表常用设置或 **设置 → 剪贴板 → 窗口失焦行为** 中选择：

| 选项 | 说明（与软件文案一致） |
|------|------------------------|
| **普通隐藏** | 失去焦点后完全隐藏窗口 |
| **贴边隐藏** | 窗口失去焦点时贴边收起；关闭后保持原位。点窗外时会先尝试贴边，若当前位置不适合贴边则回退为普通隐藏 |
| **自动折叠** | 失去焦点后收成标题栏，鼠标移入再展开 |

自动折叠时，收起后在合适条件下仍可用数字键等方式粘贴（键盘假焦点场景）。置顶窗口时的外部点击收起策略可能与未置顶不同，以当前版本行为为准。

## 无焦点模式

开启 **无焦点模式** 后，可在不抢占前台应用焦点的情况下操作剪贴板列表与部分快捷键。需要输入法搜索时，界面可能提供进入正常焦点的方式（以软件说明为准）；关闭窗口再打开通常可恢复无焦点钩子。

## 打开位置

在 **设置 → 触发** 中可配置 **打开剪贴板窗口时的位置**（例如鼠标右下、屏幕中心、鼠标周围等，以枚举选项为准）。

还可选择是否 **使用 Win+V 打开剪贴板**（通过注册表接管系统 Win+V；修改后可能需重启资源管理器后生效）。

## 相关设置入口

- 剪贴板窗口底栏 **设置** → 列表常用设置
- 主窗口 **设置 → 剪贴板** / **触发** / **个性化**

详见 [设置总览](./settings.md) 与 [粘贴与便捷粘贴](./paste.md)。
